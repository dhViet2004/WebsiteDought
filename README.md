# Dough Website

Dough Website là một dự án giao diện web cho tiệm bánh Dough Donut House. Dự án này tập trung vào việc giới thiệu các loại bánh donut đặc sắc, cung cấp thông tin cửa hàng, đặt hàng trực tuyến và hỗ trợ khách hàng qua mục FAQ.

## 📋 Tính năng chính

- **Trang chủ nổi bật:** Video banner, slogan, nút kêu gọi hành động và phần giới thiệu sản phẩm theo tuần.
- **Danh mục sản phẩm:** Trình bày các loại donut với mô tả chi tiết, hình ảnh đẹp mắt và nút đặt hàng nhanh.
- **Trang đặt hàng, blog, câu chuyện, nghề nghiệp:** Điều hướng dễ dàng qua các trang thành phần.
- **FAQ:** Hệ thống giải đáp các câu hỏi thường gặp về đặt hàng, vận chuyển, vị ngọt, gói quà,...
- **Form góp ý:** Khách hàng có thể gửi thắc mắc hoặc góp ý trực tiếp trên trang.
- **Thông tin liên hệ & địa chỉ:** Địa chỉ cửa hàng, hotline, email, liên kết mạng xã hội (Facebook, Instagram, TikTok, GrabFood, ShopeeFood).
- **Thiết kế responsive:** Giao diện tương thích trên nhiều thiết bị.

## 🛠️ Công nghệ sử dụng

- **HTML5**: Xây dựng cấu trúc trang web.
- **CSS3**: Thiết kế giao diện, hiệu ứng, responsive.
- **JavaScript**: Tương tác, điều khiển menu, FAQ, form.
- **Google Fonts, Font Awesome**: Biểu tượng và font chữ đẹp.

## 🚀 Hướng dẫn cài đặt & chạy thử

1. **Clone repo:**
   ```bash
   git clone https://github.com/dhViet2004/WebsiteDought.git
   cd WebsiteDought
   ```
2. **Mở file `index.html` bằng trình duyệt.**  
   (Không cần cấu hình backend, chỉ cần một trình duyệt web hiện đại.)

## 📂 Cấu trúc thư mục

- `index.html`: Trang chủ.
- `/html/`: Các trang thành phần (OrderForm, Signup, Story, Blog, Careers, ...).
- `/css/`: File CSS cho giao diện.
- `/js/`: File JavaScript điều khiển tương tác.
- `/images/`: Hình ảnh banner, sản phẩm, icon.
- `/videos/`: Video background cho trang chủ.
